你在帮我给一个温州小游戏补数据。游戏里玩家带 5 个外地游客逛温州老城，游客会拿真实口碑评价玩家选的店。我需要真实存在、今天还开着的地方的真实信息。

## 你的角色
只采集事实，不分析、不打分、不推荐。查不到就留空，不要猜，不要编。宁可空着，空了我们游戏就不触发那个事件；编错了是口碑事故。

## 范围
温州市鹿城区老城：北到瓯江边（含江心屿、朔门），南到锦绣路，西到九山湖、水心，东到小南路、飞霞南路。以五马街为中心步行 30 分钟。范围外不要（楠溪江、雁荡山已有）。

## 写到哪里
在飞书多维表格「瓯城1024-温州数据」里新建表「老城店铺池」。已有店（下面第 2 组列出的）也各建一条，把缺的字段补上。

## 字段（每店一条）
- 名称：和高德一致，带分店名
- 地址：高德完整地址
- 游戏类型（单选）：早餐 / 小吃 / 正餐 / 夜宵 / 手信 / 看点 / 歇脚
- 营业时间：`07:00-20:30`，分段用逗号 `11:00-14:00,17:00-21:00`；闭馆日写在后面如 `09:00-17:00（周一闭馆）`；「全天营业」就写全天营业，不要自己换算成 24 小时
- 营业状态：正常营业 / 暂停营业 / 已关闭 / 不确定 + 你核实的日期
- 大众点评评分、点评评价数：店铺页数字
- 美团评分、美团评价数：店铺页数字
- 携程评分、携程点评数：店铺页数字
- 高德评分：店铺页数字
- 人均价格：数字，免费填 0
- 招牌：≤3 个，每个 ≤6 字，逗号隔开（例：糯米饭,豆浆）
- 口味标签：≤3 个（甜/咸/鲜/辣/清淡/海鲜/油炸）
- 常见正面词、负面词：各 ≤5 个，每个 ≤5 字（例：负面「味道不如从前」「强制拍照」）
- 本地人推荐：是 / 否 / 不确定
- 饭点排队：不用排 / 偶尔 / 半小时+ / 一小时+
- 售罄时间：如「上午10点左右卖完」，查不到留空
- 平台建议停留时长：携程/美团页上写的，查不到留空
- 来源链接：每个评分对应它自己平台的链接
- 备注：≤60 字，只写事实（例：只收现金；下午卖完就关）
