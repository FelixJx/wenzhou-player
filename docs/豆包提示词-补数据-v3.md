- 地址：高德上的完整地址。分店拿不准，选评价最多的那家，在备注写选了哪家。

- 营业状态：如实选；已关的写「已关闭」，不要删记录。
- 大众点评评分、评价数：店铺页上显示的数字。
- 抖音热度：无 / 少量 / 较多 / 很多。
- 最近内容时间：能找到的最近一条相关内容的日期。
- 常见正面词、常见负面词：每个不超过 5 个字，最多 5 个，用英文逗号隔开。
- 排队情况：不用排 / 偶尔排 / 经常排半小时以上 / 经常排一小时以上 / 不确定。
- 是否需预约、适合时段、体力要求、天气季节限制、被提到的同行方式、本地人推荐：按原来的选项填。

- 备注：最多 60 个字，只写和上面字段有关的补充事实（比如票价口径不一、营业时间说法不一）。
