# 《圈地：温州》Demo 玩法设计 v1.0

日期：2026-10-25 ｜ 定位：独立原型（`qudi-demo/` 目录，不碰比赛交付版）
设计北极星：**玩家为了利（金币）而来，为了义（接住人）留下。**
上瘾目标：玩家在 90 秒内经历第一次「冒字连发 → 大额支出 → 更大回报」的锯齿曲线，之后每 30 秒一个决策点。

---

## 一、一句话与双轨目标

在真实的温州地图上，用一笔本金盘下店铺、圈占街区、接住 1024 位游客——
**利**（总金币净资产）与 **义**（接住游客数）双轨计分，结算称号「义利并举」只给双高者。

## 二、核心循环（60 秒视角）

```
收益 tick(每10s冒字) → 攒钱 → 决策点(竞拍/盘店/整改/派驻) → 大额支出 → 更大回报 → 循环
     ↑______________________________________损失规避(被截胡/维护费/走丢)______________________↓
```

每 30 秒必须出现一个决策点；每 10 秒必须出现一次可见奖励。这是上瘾的节拍器。

## 三、五大系统

### S1 选铺（0:00–0:30，教学即开局）
- 同钱开局 500 金币（1 金币=1 元）。地图 16 家真实店铺，全部白店无主。
- 店铺头顶真实口碑标签：`⭐4.8 · 👥人气旺 · 💰人均35`（数据来自 poi-facts，缺数据的店显示"新店"——天然差异化）。
- 买价 = 人均 × 评分系数（4.8→×3；4.0→×2；<3.5→×1 但触发整改线）。
- 两家 AI 同时看中 → 即时小竞拍教学（30 秒规则 10 秒讲完）。

### S2 收益与维护（经济心跳）
- 收益 tick：每 10 秒每店冒「+N」：`N = round(人气基数 × 评分倍率 × 店员匹配加成 × 连击)`。
  - 人气基数：评论数分档（500+→15、100+→10、<100→6）
  - 评分倍率：4.8→1.5、4.0→1.0、<3.5→0.8
  - 店员匹配：对 +1.5 / 错 ×0.7
  - 连击：事件题答对 ×1→×2→×3（答错归零）
- **回收 sink（防通胀三件套）**：
  1. 维护费：每 30 秒每店 −5（开局 30 秒宽限期）
  2. 竞拍投入：全款销毁（进系统，不回流）
  3. 差评事件：处理敷衍 −10
- 目标曲线：好运营 = 锯齿向上（100→竞拍-80→冒字回血→再拍）。

### S3 圈地（领地可视化）
- 盘下的店向接壤街区扩散色块（1 店=3 格，黄金铺位=6 格）。
- **连片加成**：相邻同色 ≥3 店，全体收益 +20%——制造"连片还差 1 家"的 near-miss 常驻提示。

### S4 游客店员（义轨，来自真人）
- 每店可派驻 1 名游客店员：素材 = 全场玩家报名表（困扰句 + 昵称），demo 用种子池模拟"其他玩家"。
- 人岗匹配：困扰与店铺类型相符 → 加成 + 该游客「被接住」计数 +1；错配 → 叹气降产。
- 耐心 100 起步，每游戏分钟 −5（约 20 分钟耗空）；耗空碎 1 心，3 心碎=走丢，**结算 −2 义分**。
- 派驻/换岗是决策点：好店员是稀缺资源，给谁 = 取舍。

### S5 竞拍（每 2 分钟一个高潮）
- 黄金铺位（6 格 + 高收益）刷新，底价 80，30 秒限时，**3 位 AI 对手**出价（各有性格：老油条跟 1.2 倍 / 外地炒家前 10 秒凶 / 小本经营见 120 就缩）。
- 被截胡 1.5 倍可抢回。**服务器/本地权威计时**，出价确认 1 秒锁死。
- 黄金铺位冠名真实商户（demo 内放 2 个真实冠名样例："矮人松糕黄金铺位"）。

### S6 事件题与整改
- 每 60~90 秒弹事件：谢公诗句（quiz 题库现成）/ 采购判断（真实物价）/ 差评应对三选一。
- 答对 +10 并连击+1；答错连击归零（零惩罚原则：不扣金币，扣的是"连击"这个机会）。
- 低分店（⭐<3.5）触发**金字招牌整改**：三选一整改方案 → 成功收益 ×2 ——低分店从坑变高回报赌注。

## 四、经济平衡表（demo 初版数值，试玩后调）

| 项 | 数值 | 备注 |
|---|---|---|
| 开局金币 | 500 | 三档难度 560/480/400 |
| 店价区间 | 60–150 | 人均×评分系数 |
| 好店收益 | 15/10秒 | 4.8 分 + 店员匹配 + 无连击 |
| 差店收益 | 4/10秒 | <3.5 分 |
| 维护费 | 5/30秒/店 | sink |
| 黄金铺位 | 底价 80，收益 40/10秒 | 必争 |
| 事件题 | +10 / 连击叠加 | quiz 复用 |
| 5 分钟好局净资产 | ~900–1200 | 锯齿向上 |

**通胀自检**：产出约 700/局，sink（维护+竞拍）约 400/局，净增 300 → 分数成长可见但竞拍始终"差一点够"，near-miss 常在。

## 五、Demo 范围（砍线声明）

**做**：单人 + 3 AI 竞拍对手（本地逻辑，无需联机）、16 店铺地图（12 真实 POI + 4 黄金冠名）、5 分钟一局、冒字/竞拍/事件题/派驻/整改/结算双榜。
**不做（赛后）**：真实联机房间、LBS、账号、分享卡、高德 API 实时接入（demo 用手工 facts）。
**技术栈**：与主游戏同栈（Canvas + Express），新建 `qudi-demo/` 独立目录，比赛交付版零风险。

## 六、里程碑（合计约 9 小时）
- M1（2h）经济骨架：地图+店铺卡+金币 tick+冒字 —— **可玩的第一分钟**
- M2（2h）选铺+圈地色块+维护费 sink
- M3（2h）游客店员+人岗匹配+事件题连击
- M4（2h）竞拍（3 AI 人格+30s 权威窗口）+ 结算双榜（义利并举）
- M5（1h）数值平衡 pass + 冒字音效（音高随金额）

## 七、商家联动接入点（demo 即留口）
1. 黄金铺位冠名 = 真实商户赞助位（demo 手工 2 个样例）
2. 店铺口碑标签 = 采集数据直接渲染（poi-facts）
3. 整改事件 = 真实低分店的正循环广告（赛后商业化主力）
4. 结算「到店核销」字段预留（LBS 赛后接）

## 八、验收（demo 好玩的底线）
1. 90 秒内玩家经历第一次「冒字连发→竞拍大支出→更大冒字」；
2. 一局至少 2 次竞拍、1 次扑空类事件、1 次整改决策；
3. 结算时玩家能复述"我为什么盘那家店"（决策有记忆点）；
4. 义利双榜让两种玩家都能赢（钞能力者 / 暖心派）。
