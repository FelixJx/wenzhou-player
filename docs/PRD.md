日期：2026-10-23 ｜ 状态：待确认 ｜ 目标：1024 超能 Coding 周末 · 温州站 · 游戏赛道第一 + 在地最受欢迎奖

## 0. 一句话

温州的一天有 1024 分钟。你带 5 个陌生人逛鹿城，他们每人揣着一件旅行中最怕的事——那件事是**另一个真人**开局时写下的。午夜前把大家带回家，路上还会遇到和温州有渊源的古今名人。玩一局，认识一座城。

## 2. 视觉决策：像素 2.5D 斜俯视（不做 3D）

| | 像素 2.5D 斜俯视 | 3D 模拟温州 |
|---|---|---|
| 一天内能到的效果 | 有摄像机、3 处地标、昼夜调色、5 个跟随小人、气泡清晰可读 | 低多边形方块城，没有材质，像技术 demo |
| 手机性能 | Canvas 2D，任何手机 60fps | WebGL 在低端机掉帧，续航差 |
| 信息可读性 | 5 个游客 + 气泡 + 图标一屏看清 | 视角一转就看不到队伍后面的人 |
| 资产来源 | AI 出像素图切片，30 分钟一张地标 | 建模、贴图、碰撞、相机各要一天 |
| 评审原话 | "加摄像机 + 精修 3 个地标 + 一层光影，2～3 天能翻盘" | 评审未建议 |

**结论**：像素 2.5D 斜俯视。惊艳感靠**摄像机跟随 + 昼夜五档调色 + 雨/灯笼粒子 + 3 处手绘地标 + 名人出场时的全屏卡**，不靠维度。3D 作为赛后方向。

## 3. 角色设定

### 3.1 AI 游客（困扰标签 = 名字）

| 名字 | 困扰 | 需要什么 | 不满足时的征兆 → 后果 | 教玩家什么 |
|---|---|---|---|---|
| 走不动 | 走太久 | 每隔一段路有歇脚点 | 冒汗变慢 → 坐地上不走 | 看歇脚点图标 |
| 吃不惯 | 吃不合口味 | 13:00 前吃一次本地小吃 | 肚子冒泡 → 自己钻进路边小吃店 | 温州小吃有哪些 |
| 怕挤挤 | 人太多 | 避开人潮区，走小巷 | 在人潮区掉心 → 被人群冲散 | 五马街几点人多、小巷在哪 |
| 买买买 | 没时间买手信 | 回家前去过一次手信店 | 路过店就盯着看 → 到家时留在店门口 | 温州手信是什么 |
| 没劲儿 | 太无聊 | 去一处看点，连续两站不重样 | 东张西望 → 跟别的旅行团走了 | 温州有什么看点 |
| 催催催 | 太赶 | 少停站、停站短 | 每多停一站掉心 → 跑到最前面拽全队 | 时间取舍 |
| 憋不住 | 找厕所 | 每 3 站内经过一个厕所标记 | 原地转圈 → 乱跑脱队 | 看地图厕所标记 |
| 都行哥 | 随便（每局必有 1 个） | 无 | 从不掉心 | 结算台词："都说了随便。但你安排得挺好。" |

- 每局 5 人（初级）：都行哥 ×1 + 其余从 7 种里抽 4 种，不重复，**至少有一对冲突**（走不动 vs 催催催 / 怕挤挤 vs 买买买）。
- 每位游客头顶显示：名字 + 困扰图标 + 3 颗心 + 一句话（来自困扰池，≤10 字，真人写的）。
- 标准 6 人 / 困难 7 人在第一局后解锁；困难局有"传染"。

### 3.2 名人 NPC（第一版 4 人，第二版 +3）

| 名人 | 温州渊源（需现场复核出处） | 触发 | 反应类型 | 知识点 |
|---|---|---|---|---|
| 谢灵运 | 永嘉太守，山水诗鼻祖，《登池上楼》 | 路线含 ≥1 看点，在墨池/江滨停站 | **写诗**：AI 代拟四句，嵌玩家名和走过的地名；生成旋转收藏卡 | "池塘生春草"写于温州 |
| 王羲之 | 传为永嘉郡守，墨池传其洗砚处 | 墨池停站 ≥64 分钟 | **陪玩**：描一笔"永"字，成功全队 +1 心 | 墨池地名由来 |
| 文天祥 | 1276 年镇江脱险后经海路至温州，驻江心屿；岛上有文信国公祠 | 江滨码头，黄昏后 | **叙事**：一句话，不给奖励，预埋"回头" | 江心屿与文天祥 |
| 苏步青 | 平阳人，数学家 | 游客中心开局/结算 | **1024 代言**：解释 2¹⁰，结算报"你用了 973 分钟" | 温州出数学家 |
| 朱自清（v2） | 1923 年任教温州十中，《温州的踪迹·绿》 | 下雨 + 歇脚点 | 念一段，走不动满星 | 梅雨潭 |
| 弘一法师（v2） | 驻锡温州庆福寺十余年 | 小巷 + 全队无人掉心 | 只给卡："慢一点" | 庆福寺 |
| 高则诚（v2） | 瑞安人，《琵琶记》，温州南戏 | 戏台/夜间 | 对戏词三选一 | 南戏发源地 |

**AI 生成规则**：输入 = 人设卡（核实生平 3 条 + 原句 1 句 + 口吻 + 禁区）+ 当前路线 + 游客标签 + 地点天色；输出 ≤40 字或四行诗；**3 秒超时切模板**（每人 3 条预写）；屏幕标注"AI 代拟，非原作"；核实原句标"原作"。

### 3.3 知识层（边玩边学）

- 每个地点停站时，底部出一行"**温州一句话**"（≤30 字，带出处），不打断，3 秒淡出。
- 名人出现时，卡背是知识点。
- 结算页"**今天你认识了温州的 3 件事**"，从本局触发的知识里抽 3 条；图鉴记录累计（本机）。
- 内容全部来自 `content/knowledge.json`，每条带 `source` 字段，没有出处的不入库。

## 4. 核心流程

```
S0 开局：昵称 + 写下最怕的事（选标签 + ≤10 字）        ≤40 秒
S1 接团：5 位游客亮相，各念自己那句话                   10 秒
S2 排路线：点地图 3～5 个地点，游客实时冒泡表态           ≤30 秒
S3 出发：实时带队，1 秒 = 4 游戏分钟，共 256 秒
     中断类型：游客要闹 / 两人打架 / 名人出现 / 城市事件 / 有人掉队 / 主动改道
S4 结束：提前回家 或 读数 1024 → 全黑 → 点人头 → [回去找他 +64分钟][继续回家]
S5 结算：带回 x/5 · 记住你 y/5 · 到家时刻 · 游客台词 · 3 条知识 · 称号
S6 升华屏（仅第一局一次）→ 再来一局 / 我写的那句去哪了
```

### 4.1 操作（只有两种）
- **走**：点地面（手机）/ WASD（桌面），队伍贪吃蛇跟随；走进地点自动停站，时间跳 32 分钟（歇脚 64）。
- **哄**：点游客，+1 心，每人每局 2 次；第 2 次台词"你刚才不也让我等了半天"，第 3 次无效。

### 4.2 中断（每 20～30 秒一次，永远两个按钮）

| 中断 | 触发 | 按钮 | 后果 |
|---|---|---|---|
| 要闹 | 某人心=1 | 点他哄 / 就近停站 / 不管 | 见 3.1 |
| 打架 | 冲突对同时冒泡 | [歇一下][接着走] | 必得罪一个 |
| 名人 | 见 3.2 | [陪他一会儿 32 分钟][点头走过] | 得卡 / 错过 |
| 城市事件 | 雨 / 人潮 / 修路 | [绕小巷][硬穿] | 时间 vs 掉心 |
| 掉队 | 心=0 | [回去领他 +64][继续走] | 与结尾同构 |
| 问路 NPC | 玩家点 | 花 32 分钟 | 给一条线索，不给方案 |

### 4.3 结算与榜

- 记住你：困扰被化解的人 ⭐。称号：本地通（5/5）/ 贴心向导（≥3）/ 赶路人（最快但 ≤1）/ 丢三落四（丢 ≥2）。
- 三榜：被记住榜（主）/ 最快榜（全员带回且未超时）/ 最丢人榜（丢人数，不发奖）。
- 回头代价 = +64 分钟，可能"超时到家"，不进最快榜。

### 4.4 1024 贯穿
时间轴 07:00→00:04 = 1024 分钟；顶部内存条样式进度条只报读数；天色 256/512/768/972 五档只换调色板；结尾句"1024 分钟很短。但一座城愿意等你过完它。"**不报任何现场人数。**

## 6. 技术方案

- **前端**：单目录静态文件，Canvas 2D + 原生 JS，无构建、无外部 CDN。竖屏优先（9:16），桌面自适应。模块：`engine`（循环/相机/输入/寻路/渲染）、`rules`（游客/标签/评分/名人触发）、`ui`（流程页/HUD/结尾/结算）、`content`（JSON）。
- **后端**：Node + Express + SQLite，4 个接口：`POST /troubles`、`GET /troubles/sample?n=5&exclude=<seat>`、`POST /runs`、`GET /boards`；`POST /celebrity` 代理 Qwen（3 秒超时返回模板）。敏感词在服务端 + 客户端各过一遍。
- **离线兜底**：`content/seed_troubles.json`（真人写的种子困扰 ≥40 条）；所有接口失败时静默切本机，隐藏"我写的那句去哪了"。
- **部署**：静态文件 + Node 服务同机（已有 ECS），Nginx 反代，HTTPS；二维码指向 `https://<域名>/play`。
- **本机存储**：`has_played`、`seen_ending`、最高分、图鉴、未上传困扰队列。
