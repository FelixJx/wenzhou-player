# 豆包提示词：《温州玩家》知识核对（10/23 晚）

> 给当前主项目《温州玩家 · 1024分钟》用。它不用真实门店数据，用的是 52 条「温州一句话」，每条标了出处。
> 现场评委和观众是温州本地人，一条说错就很扎眼。下面整段复制给豆包。

---

你在帮我核对一个温州小游戏里的 51 条知识。只查公开资料、记录事实，不要改写句子，不要下"好不好"的判断。

## 写到哪里
在飞书多维表格「瓯城1024-温州数据」里新建一张表，叫「知识核对」，字段：
- 编号（下面清单前面的数字）
- 原句（照抄清单里的句子）
- 查到的说法（来源里和这件事有关的要点，自己的话概括，不超过 40 字，不要整段复制）
- 是否一致：一致 / 有出入 / 没找到
- 有出入的地方（只在"有出入"时填：哪个数字、年份、人名、地名不一样，不超过 30 字）
- 来源链接 1、来源链接 2（你实际打开过的页面，优先：政府/文旅局网站、博物馆、权威百科、新闻媒体；尽量两个不同网站）
- 清单里写的出处是否查得到：查得到 / 查不到 / 不确定

## 重点盯这几类
- 年份、数字（建于哪个朝代、哪一年列入名录、瀑布多高）
- 诗句原文和诗名（逐字对）
- "相传"的说法：只要查到有公开资料这么讲就算一致，不用证明传说是真的
- 列入非遗、考古发现、世界航标遗产这类"入选"信息：核对年份和名单名称

## 规则
- 只看公开页面，正常浏览速度。
- 不复制原文段落，概括成自己的话。
- 查不到就写"没找到"，不要猜。
- 每核完 10 条，在对话里回报一句：几条一致、几条有出入、几条没找到。
