# Cozy Isometric — 风格规范

从参考图（等距 2.5D 治愈系模拟经营）反推出的可执行视觉规则。做新界面前先读这一页，能保证新增内容不跑偏。

---

## 一、一句话定位

**等距 30° 视角下的平涂世界**：米白环境色铺底，高饱和功能色点缀，所有体积感靠"亮面 / 背光面"两阶色差和硬边投影完成，不用模糊、不用渐变过渡、不用发光特效。

---

## 二、五条铁律

| # | 规则 | 为什么 |
|---|---|---|
| 1 | **投影必须是硬的** | `box-shadow: 0 Npx 0 <色>`，blur 恒为 0。模糊阴影会立刻破坏"实体感"，变成网页卡片。 |
| 2 | **每个面最多三阶明暗** | 受光 / 主色 / 背光。不做连续渐变，色块之间是硬截止。 |
| 3 | **描边只用墨色，不用纯黑** | `#2E3A33` 深墨绿。3px 用于容器，2px 用于图标，1.5px 用于分隔线。 |
| 4 | **80 / 20 配色** | 80% 面积给低饱和环境色（米白、石灰、草绿），20% 给高饱和功能色（橘、珊瑚、薄荷、天蓝、玫红）。功能色只在"需要被点"的地方出现。 |
| 5 | **圆角小而圆，不夸张** | 小元件 4–6px，容器 10–14px，胶囊 999px。上限 20px，再大就变成手机 App 卡片。 |

---

## 三、光影

**光源固定在左上 45°。** 所有物件的受光面朝左上，背光面朝右下，落地投影落在右下方。

三件套组合出体积感：

```css
/* 容器 */
box-shadow:
  0 6px 0 <背光色>,           /* 硬投影，同色系加深 */
  0 10px 0 rgba(80,72,52,.16), /* 二次落地投影，更淡 */
  inset 0 3px 0 rgba(255,255,255,.55),  /* 顶部内高光 */
  inset 0 -4px 0 rgba(80,72,52,.12);    /* 底部内暗边 */
```

按钮按下时整体下沉 4px，同时底边厚度同步收薄 —— 这是"按下去"的关键，不是变暗。

---

## 四、色彩

### 环境色（铺底）

| 用途 | 色值 |
|---|---|
| 面板主面 | `#F7F2E3` |
| 面板次面 / 分区 | `#EFE7D2` |
| 凹陷底 / 输入框 | `#E3D9BE` |
| 石材 | `#C9C7BC` / `#ABA99D` / `#8B8980` |
| 草皮 | `#C6CB98` / `#A5AC74` |
| 树冠 | `#6FA35A` / `#3F6B3E` |

### 功能色（每色三阶，必须配齐）

| 语义 | 受光 | 主 | 背光 |
|---|---|---|---|
| 主操作 / 收益 | `#FFC46B` | `#F2A03D` | `#C9751F` |
| 危险 / 扣除 | `#FF8A70` | `#E4553F` | `#A93A28` |
| 成功 / 恢复 | `#86E0BC` | `#57C79A` | `#2E8C68` |
| 信息 / 水系 | `#A7C8E8` | `#7FA8D0` | `#51719B` |
| 稀有 / 强调 | `#FF8BA9` | `#E4587E` | `#A93255` |

**只要三阶配齐，任何新增语义色都能自动融进体系。** 缺一阶就会出现"贴纸感"。

### 墨色

`#2E3A33`（描边/主文字）→ `#4A554C`（正文）→ `#7A837A`（次要）→ `#A8AFA5`（占位/禁用）

---

## 五、几何

- **等距角**：2:1 菱形，即 `transform: scale(1, .5) rotate(45deg)`。所有"地块""网格"都按这个比例切。
- **描边**：容器 3px，图标 2px，字号 ≥ 18px 的文字可加 3px 描边（`paint-order: stroke fill`）。
- **圆角**：`4 / 6 / 10 / 14 / 20 / 999`，不要出现 8px、12px 这类中间值，会显得犹豫。

---

## 六、排版

- 中文字体：`PingFang SC` / `Yuanti SC`（圆体优先），字重 700–900。**游戏 UI 一律不用细字重。**
- 数字：`Baloo 2` / `Nunito` / `PingFang SC`，`font-variant-numeric: tabular-nums` —— 数值变化时不能跳动。
- 压在场景上的文字用白色 + 墨色描边，压不压得住取决于描边而不是阴影。
- 字号阶梯：11 / 13 / 15 / 18 / 24 / 32 / 44。

---

## 七、动效

- 时长：`120ms`（反馈）/ `220ms`（状态切换）/ `380ms`（入退场）。
- 曲线：出场用 `cubic-bezier(.22,1,.36,1)`，弹入用 `cubic-bezier(.34,1.56,.64,1)`（带过冲）。
- 位移优先于透明：按下去是 `translateY(4px)`，不是 `opacity`。
- 禁止：外发光呼吸、大面积毛玻璃、3D 翻转。

---

## 八、七个常见错误

1. ❌ 用 `box-shadow: 0 4px 12px rgba(0,0,0,.1)` —— 模糊阴影，立刻出戏。
2. ❌ 用 `#000000` 描边 —— 太硬，画面变脏。用 `#2E3A33`。
3. ❌ 功能色只给一阶 —— 按钮会变成扁平色块。
4. ❌ 圆角 24px+ —— 变成 SaaS 后台。
5. ❌ 面板上用渐变背景 —— 平涂才是本体，渐变只允许出现在 `linear-gradient(180deg, 亮 0%, 主 46%, 主 100%)` 这种模仿受光的窄幅用法。
6. ❌ 给稀有物品加光晕 —— 用边框色 + 底色渐变区分稀有度就够了。
7. ❌ 图标描边粗细不统一 —— 一套图标内必须同一粗细。
